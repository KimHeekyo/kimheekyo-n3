# 김희교 N3 공부 단어집

웹에서는 `index.html`을 열어 사용할 수 있고, HTTPS 서버에 배포하면 아이폰 홈 화면에 앱처럼 설치할 수 있습니다.

## 기능

- OpenJLPT 후보 목록 1,791개의 표기·뜻·읽기·품사를 검수하여 전체 학습에 사용
- 일본어→한국어 / 한국어→일본어 4지선다 퀴즈
- 히라가나 읽기를 `힌트보기` 버튼으로 확인
- 검색 및 품사 필터
- 오늘의 문제 수와 정답률, 외운 단어, 오답 자동 저장
- 모든 코드와 데이터가 로컬에 있어 인터넷 연결 불필요

학습 기록은 브라우저의 `localStorage`에 저장됩니다. 다른 브라우저나 기기로 자동 동기화되지는 않습니다.

## 아이폰에 설치하기

1. 이 폴더를 HTTPS를 지원하는 정적 웹 호스팅에 배포합니다.
2. 아이폰 Safari에서 배포 주소를 엽니다.
3. Safari의 공유 버튼을 누르고 **홈 화면에 추가**를 선택합니다.
4. 홈 화면의 `김희교 N3` 아이콘으로 실행합니다.

첫 실행에서 앱 파일과 단어 데이터가 기기에 저장되므로 이후에는 인터넷 연결 없이 학습할 수 있습니다. 새 버전이 배포되면 앱 안에 **새 버전이 있어요** 알림이 나타나며, 업데이트 버튼을 누르면 학습 기록을 유지한 채 새 파일을 적용합니다.

서비스 워커는 보안 정책상 `file://` 주소에서는 동작하지 않습니다. 오프라인 설치와 자동 업데이트를 사용하려면 HTTPS 배포 주소가 필요합니다.

## 새 버전 배포

파일을 수정한 뒤 `sw.js`의 `CACHE_VERSION`을 새로운 값으로 올리고 전체 폴더를 다시 배포합니다. 예를 들어 `kimheekyo-n3-v1` 다음 버전은 `kimheekyo-n3-v2`로 변경합니다. 기존 학습 기록 저장 키는 그대로 유지됩니다.

배포 전 데이터 검사는 다음 명령으로 실행합니다.

```sh
python3 scripts/audit_vocabulary.py
```

## 데이터 출처

OpenJLPT 데이터는 N3 학습 후보 목록으로 보존하고, 표기·한국어 뜻·읽기·품사를 별도 사전 자료와 대조한 결과를 1차 학습 데이터로 사용합니다. 아직 전수 검수 중인 예문과 번역은 1차 앱에 노출하지 않습니다. 공식 JLPT는 2010년 개정 이후 급수별 고정 어휘 목록을 공개하지 않으므로, 이 앱의 목록은 공식 완전 목록을 의미하지 않습니다. 자세한 출처는 `NOTICE.md`를 참고하세요.
